## 🚀 What is JET Launcher?

`JET Launcher` is a command-line Python program that lets you:

- Add file paths in a simple `file_list.txt`.
- Run the script.
- Choose a file from a numbered menu.
- Boom! It opens instantly.

No mouse. No delay. Just sweet, fast file launching.

---

## 🧰 How to Use

1. Create a file named `file_list.txt` in the same directory as the script.
2. Add full paths to the files you want quick access to. One per line:
   - C:\Users\You\Documents\important_report.docx  
   
   - D:\Videos\funny_dog.mp4  
   
   - E:\Work\spreadsheet.xlsx

3. Run the Python script:

```bash
python main.py
```

   4. Select the file number from the menu and press enter.

## Example

```
=== JET Launcher Menu ===
1. important_report.docx
2. funny_dog.mp4
3. spreadsheet.xlsx
0. Exit

Which file would you like to launch? (Enter number): 2
Launching: D:\Videos\funny_dog.mp4
```
